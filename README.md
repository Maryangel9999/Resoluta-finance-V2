# Resoluta Finance V2

Resoluta Finance é uma plataforma de gestão financeira desenvolvida pela Resoluta AGI para apoiar microempreendedores, autônomos e pequenos negócios na organização financeira e tomada de decisões.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Supabase
- PostgreSQL
- n8n
- VLibras

## Próximas Implementações

- Gamificação
- Login e autenticação
- Recuperação de senha
- Medidor de força da senha
- Bloqueio após 3 tentativas
- PWA Android e iOS
- Assistente Virtual em Libras
